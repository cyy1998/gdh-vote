# 工会票号按录入组独立编号

工会委员会选举的三个录入组各自维护可复用的组内序号，并以 `组号-序号` 组成票号，例如三个组的首张票分别为 `1-1`、`2-1`、`3-1`。这让纸票与负责录入的组可以直接对应；撤销只释放本组空号，经审组继续使用纯数字票号。

## Considered Options

- 在现有全局序号前增加组号：改动较小，但序号不能表达本组录入次序。
- 组内序号永久递增：审计引用稳定，但撤销后会留下空号并可能超过投票人数上限。
- 迁移旧记录并按组重编号：可以保留数据，但会改变已经展示过的票号。

## Consequences

- 有效票号在“选举、录入组、组内序号”范围内唯一，不同工会组可以同时拥有相同序号。
- 投票人数上限同时约束选举的未撤销总数与各组当前最大序号。
- 启用新规则前清空工会选举记录，不迁移或自动重编号既有工会记录。
