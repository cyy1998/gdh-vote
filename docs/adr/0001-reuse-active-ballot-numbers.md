# 撤销后复用票号并保留独立审计记录

本决策的撤销审计与空号复用原则继续有效；工会委员会选举“所有录入组共享号码池”的部分已由 [ADR-0002](./0002-number-union-ballots-by-recording-group.md) 取代，经费审查委员会选举仍使用单组号码池。

每项选举不再把票号作为贯穿全部历史的永久递增序号，而是把它定义为 `1..投票人数上限` 中由所有录入组共享的可复用号码。撤销记录继续以永久记录编号保留审计历史，但不再拥有当前票号；其原票号返回号码池，后续提交取得最小可用票号，因此满额时未撤销记录的票号严格覆盖完整范围。

## Considered Options

- 保留全历史递增且永不复用的票号：审计引用简单，但撤销后最大票号可能超过投票人数上限。
- 撤销时删除旧记录再复用号码：号码范围简单，但失去撤销历史。
- 自动重排现有有效票号：可以消除空缺，但会改变已经提交并被现场人员看到的票号。

## Consequences

- 永久记录编号在全部历史中唯一；票号只要求在同一选举的未撤销记录中唯一。
- 撤销记录保留原票号分配值作为数据库审计数据，但历史界面的票号显示为 `-`，且不展示原票号或永久记录编号。
- 票号分配、撤销、唯一性检查和人数上限检查必须在同一数据库事务中完成。
- 启用新规则前由管理员使用旧版本清空两项选举的全部记录，不迁移既有票记录。
